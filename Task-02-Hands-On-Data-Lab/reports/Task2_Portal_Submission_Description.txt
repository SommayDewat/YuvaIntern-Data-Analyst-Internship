This report documents the practical work completed for Task 2, Hands-On Data Lab Implementation, as part of the Data Analyst internship. The objective was to build and use a Python data analysis environment and apply data manipulation, data-quality validation, exploratory analysis, aggregation, and visualization to a structured dataset.

A synthetic retail sales dataset containing 20 sample orders was created with fields for order ID, date, region, product category, product, quantity, unit price, and discount. Python and Pandas were used to load the data, inspect data types, check missing values and duplicate rows, validate numerical fields, and convert dates into an appropriate format. Feature engineering was applied to calculate gross sales, net sales, and month-level values. The analysis then grouped sales by product category, region, and month to produce summary tables and business-oriented comparisons.

Matplotlib was used to create charts showing net sales by category, net sales by region, and the monthly sales trend. The workflow exports a cleaned dataset, category and regional summaries, monthly sales results, and a JSON data-quality summary. A Jupyter notebook presents the analysis steps in a structured and reproducible format, while a Python script can run the analysis independently.

The sample produced total net sales of ₹273,500 across 20 orders and 39 units. Electronics had the highest category sales, North had the highest regional sales, and March had the highest monthly sales in the sample. These observations are descriptive only. The dataset is synthetic and small, so the findings must not be interpreted as evidence of actual retail business performance. The discount is treated as an order-level amount, an assumption that would need confirmation in a real dataset. The project demonstrates a complete learning workflow from data loading and cleaning to aggregation, visualization, and communication of limitations.
