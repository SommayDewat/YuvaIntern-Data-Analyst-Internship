This report presents the practical work completed for Task 1, Data Science Fundamentals Assessment, as part of the Data Analyst internship. The objective was to demonstrate a foundational understanding of Python programming, statistical concepts, data manipulation, visualization, and data-quality practices through reproducible exercises.

The first section uses Python variables, lists, built-in functions, arithmetic operations, and conditional statements to calculate total and average marks and classify a sample result. Data types and common collections, including strings, integers, floating-point numbers, booleans, lists, and dictionaries, are also demonstrated. The statistical section uses NumPy and SciPy to calculate mean, median, mode, minimum, maximum, range, population variance, and population standard deviation for a sample dataset. Pandas is then used to create and inspect DataFrames, examine data types and descriptive statistics, and calculate department-level averages with groupby. A Matplotlib bar chart presents the sample student marks in a clear visual format.

The report also covers a structured data-quality exercise using a synthetic customer dataset. The dataset intentionally contains missing values, an exact duplicate row, and an implausible age value. The workflow identifies these issues, removes the exact duplicate row, converts out-of-range ages to missing values, and fills selected missing numerical values using column medians for demonstration. Validation assertions check identifier uniqueness, age ranges, non-negative purchase amounts, remaining missing values, and duplicate rows. The cleaned data and a JSON quality summary are saved as project outputs.

The repository includes the Jupyter Notebook, report, README, dependency list, cleaned CSV, and quality-summary JSON file. All examples use synthetic learning data and should not be interpreted as findings about real customers or business performance. The project emphasizes clear documentation, reproducibility, validation, and careful interpretation of data-cleaning decisions. In real-world analysis, imputation and duplicate-handling rules must be chosen according to data context and business requirements.
